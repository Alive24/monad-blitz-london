The problem

It's a cliff, not a slope

0.1% underwater gets the same treatment as 10% underwater: total closure. Flash wicks that revert in seconds destroy positions that would have been healthy a minute later.

The penalty is a guess

A fixed bonus overpays keepers in calm markets and underpays them in violent ones. The right number changes minute to minute — no constant is correct.

Interest rates became curves. Swap fees went dynamic. The liquidation penalty is one of the last unpriced constants in DeFi.

The mechanism

1

Slice, don't seize

When health < 1, a 2.5% micro-slice goes up for sale — not the whole position. Each cleared slice repays debt, nudging health back up.

2

Auction the penalty itself

The keeper discount starts at 0bps and ramps +10bps per block until claimed. Calm market: ~20–30bps, since waiting means being front-run. Violent market: 60–80bps. The penalty is discovered per-slice by competition. Nobody sets it.

3

Stop when healthy — the position survives

The moment health crosses back above 1, slicing halts — the borrower keeps everything unsold. A conventional backstop remains below health 0.92, so the bad-debt guarantee never weakens.

An engine, not a protocol

Slicer bolts onto any margin system that implements three functions. The demo's margin ledger is a deliberately dumb stub; the engine is the product.

interface ISliceable {
    // what is the position?
    function getPosition(address account) external view returns
        (uint256 collateral, uint256 debt, uint256 price, uint256 health);

    // the only two powers the engine ever needs
    function seizeCollateral(address account, address to, uint256 amount) external;
    function repayDebt(address account, uint256 amount) external;
}

Slice sales can settle through any AMM — a Uniswap v4 route (live on Monad mainnet) takes keeper capital requirements to zero. The live demo runs the replay above against real testnet contracts, every claim a real transaction at 300ms cadence.

The obvious objections

Can't keepers collude and wait for max discount?

Any keeper can defect one block early and take the whole slice. At 10bps per 300ms block, cartel discipline breaks faster than it forms — first-claim-wins is the enforcement mechanism.

Does gradualism create bad debt in a real crash?

No. Below health 0.92 conventional full liquidation is available, unchanged. Slicer only replaces the cliff in the 0.92–1.00 band, where gradualism is safe by construction.
